# homebrew-mkmsbr

Homebrew tap for [`mkmsbr`](https://github.com/jma24/mkmsbr) — a clean-room MIT
library and CLI for writing Microsoft-compatible MBR and FAT32/NTFS boot
records.

## Install

```sh
brew install jma24/mkmsbr/mkmsbr
```

Or tap once and install by short name:

```sh
brew tap jma24/mkmsbr
brew install mkmsbr
```

## Upgrade

```sh
brew update
brew upgrade mkmsbr
```
